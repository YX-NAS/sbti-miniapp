## 4. 使用逻辑变化

### 4.1 快测进入完整版

当前所有快测进入完整版前，仍保持：

- **先分享**
- **再解锁完整版**

说明：

- 前端是通过分享按钮触发解锁
- 由于微信前端能力限制，前端无法区分“分享给好友”还是“分享到群”
- 只要是从分享按钮发起，即视为完成解锁流程

### 4.2 历史记录与续测

- 完整版中途退出后，会保留本地进度
- 再次进入测试中心或历史记录页时，会出现继续入口
- 完成后的结果仍会写入历史记录

## 6. 建议验收清单

建议按下面顺序检查：

1. 测试中心可看到连续访问卡
2. 做任意快测后，结果页可看到“猜你喜欢”
3. 快测结果页仍需分享后才能解锁完整版
4. 完整版中途退出后，再回测试中心可看到“继续上次完整版”
5. 历史记录页可看到推荐卡和续测卡
6. 配置台可看到“运营建议”和“一键应用今日热推”
7. `npm run build:weapp` 可成功构建
