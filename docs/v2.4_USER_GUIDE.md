# v2.4 小白指导手册

> 适合对象：第一次接触这个项目、需要自己导入和运行微信小程序的人  
> 使用场景：本地查看、继续开发、导入微信开发者工具、配置云开发

---

## 1. 先知道你要做什么

如果你只是想把项目跑起来，按下面顺序做就行：

1. 安装依赖
2. 构建小程序
3. 用微信开发者工具导入
4. 配置云开发
5. 按验收清单检查

---

## 2. 项目里最关键的几个目录

| 目录 / 文件 | 作用 |
|------|------|
| `src/` | 源代码，真正开发时主要改这里 |
| `dist/` | 构建后的微信小程序产物 |
| `cloudfunctions/` | 云函数代码 |
| `project.config.json` | 微信开发者工具项目配置 |
| `docs/v2.4_UPDATE_NOTES.md` | 本版本更新说明 |
| `docs/v2.3_DEPLOY_GUIDE.md` | 上一版部署说明 |

---

## 3. 第一步：安装依赖

在 `sbti-miniapp` 项目目录打开终端，执行：

```bash
npm install
```

如果已经装过依赖，也可以直接执行下一步。

---

## 4. 第二步：构建微信小程序

执行：

```bash
npm run build:weapp
```

看到构建成功后，会生成或更新：

```text
dist/
```

这个目录就是微信开发者工具要读取的小程序代码。

---

## 5. 第三步：导入微信开发者工具

打开 **微信开发者工具** 后，按下面操作：

1. 点击 **导入项目**
2. 选择项目目录：`sbti-miniapp`
3. AppID 使用项目里的现成配置
4. 确认工具能识别 `project.config.json`

当前配置文件里的关键信息是：

- 小程序产物目录：`dist/`
- 云函数目录：`cloudfunctions/`
- AppID：`wx1575aed7b9b0eb82`

---

## 6. 第四步：配置云开发

如果你只想看页面，不一定马上要配云开发。  
但如果你想用 **登录、历史同步、云记录**，就必须完成下面几步。

### 6.1 开通云开发环境

在微信开发者工具顶部点击 **云开发**，新建一个环境，记下你的环境 ID。

示例：

```text
sbti-miniapp-prod-xxxxxx
```

### 6.2 替换环境 ID

打开文件：

```text
src/utils/userIdentity.ts
```

找到这一行：

```ts
const CLOUD_ENV_ID = 'sbti-miniapp-prod'
```

把它改成你自己的真实环境 ID。

### 6.3 上传并部署云函数

在微信开发者工具里，对下面两个目录分别执行：

- 上传并部署：云端安装依赖

需要部署的云函数目录：

- `cloudfunctions/getOpenid`
- `cloudfunctions/syncRecords`

### 6.4 创建数据库集合

在云开发数据库中创建：

```text
test_records
```

这是用来保存历史测试记录的集合。

---

## 7. 第五步：开始体验和检查

建议按这个顺序体验：

### 7.1 先看测试中心

进入测试中心后，重点检查：

- 是否能看到核心测试和专题测试
- 是否能看到连续访问卡
- 如果之前做过完整版，是否会出现“继续上次完整版”

### 7.2 再测一个专题快测

任选一个：

- 学生性格
- 情感模式
- 学习状态
- 学生人格倾向
- CatTi

做完后检查：

- 结果页有没有“猜你喜欢”
- 有没有“分享后解锁完整版”按钮

### 7.3 进入完整版

注意当前逻辑：

- 所有快测进入完整版前，**必须先分享**
- 分享成功后，完整版会解锁

### 7.4 查看历史记录

完成完整版后，去历史记录页检查：

- 是否生成记录
- 是否能点击回看
- 是否能看到推荐卡
- 是否能看到“继续上次完整版”
- 点击“☁️ 同步”是否正常

---

## 8. 配置台怎么打开

配置台默认是隐藏的。

打开方式：

1. 进入 **测试中心**
2. 连续点击标题 **“🧪 测试中心”** 6 次
3. 右上角会出现 **配置台**

配置台目前可以做这些事：

- 调整首页热门测试顺序
- 隐藏 / 显示入口
- 设置每日投放题目
- 查看完整版漏斗
- 查看运营建议
- 一键应用今日热推顺序

---

## 9. 彩蛋怎么触发

首页标题 **“星座人格实验室”** 连续点击 6 次，会触发约 3 秒的放烟花效果。

这个是彩蛋，不影响正常功能。

## 10. 常见问题

### 10.1 为什么可以进项目，但同步失败？

大概率是下面几种原因：

- 云开发环境还没创建
- `CLOUD_ENV_ID` 没替换成你自己的
- 云函数还没部署
- 数据库集合 `test_records` 还没创建

### 10.2 为什么我做了一半完整版，回来还有进度？

这是正常的。  
项目会把未完成的完整版进度先存在本地，方便你下次继续。

### 10.3 为什么分享按钮点一下就算解锁？

因为小程序前端侧无法准确判断你最终分享给了谁。  
当前逻辑是：**只要从分享按钮发起分享，就视为完成解锁**。

### 10.4 我改了代码，但微信开发者工具里没变化怎么办？

按这个顺序检查：

1. 先重新执行 `npm run build:weapp`
2. 确认 `dist/` 已更新
3. 回到微信开发者工具重新编译
