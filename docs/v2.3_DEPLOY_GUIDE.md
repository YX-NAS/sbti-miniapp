## 3. 本地部署方式

### 3.1 安装依赖

在项目根目录执行：

```bash
npm install
```

### 3.2 构建微信小程序产物

```bash
npx taro build --type weapp
```

构建完成后，微信小程序产物位于：

```text
dist/
```

---

## 4. 微信开发者工具导入

### 4.1 导入方式

在微信开发者工具中选择：

1. **导入项目**
2. 选择项目目录：`sbti-miniapp`
3. AppID 使用当前项目配置中的 AppID
4. 确认 `project.config.json` 已被识别

### 4.2 关键目录

- 小程序代码目录：`dist/`
- 云函数目录：`cloudfunctions/`

---

## 5. 云开发配置步骤

### 5.1 开通云开发

在微信开发者工具顶部点击 **云开发**，创建一个环境，拿到环境 ID，例如：

```text
sbti-miniapp-prod-xxxxxx
```

### 5.2 替换环境 ID

打开文件：

```text
src/utils/userIdentity.ts
```

将：

```ts
const CLOUD_ENV_ID = 'sbti-miniapp-prod'
```

改成你自己的真实环境 ID。

### 5.3 上传云函数

在微信开发者工具中，对以下两个目录分别执行“上传并部署：云端安装依赖”：

- `cloudfunctions/getOpenid`
- `cloudfunctions/syncRecords`

### 5.4 创建云数据库集合

在云开发数据库中创建集合：

```text
test_records
```

建议权限：

- 仅管理端可读写  
或
- 按 openid 做访问隔离

---

## 6. 验收清单

部署后建议按下面顺序检查：

1. 首页、测试中心、CatTi、学生人格倾向页可以正常打开
2. 快测结果页出现“分享后解锁完整版”按钮
3. 解锁后可进入完整版
4. 完整版完成后写入历史记录
5. 历史记录页可查看结果
6. 点击“☁️ 同步”不会报错
7. 云函数部署后，数据库中能看到 `test_records` 数据
